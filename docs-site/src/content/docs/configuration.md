## Добавление Yandex Alice в Music Assistant

1. Откройте **Music Assistant → Настройки → Плагины**.
2. Нажмите **«+ Добавить»** и выберите **Yandex Alice**.
3. Следуйте инструкциям на экране для настройки провайдера.

## Параметры подключения

| Параметр | Значение |
|:---------|:---------|
| **Сервис** | [https://dialogs.yandex.ru/developer](https://dialogs.yandex.ru/developer) |
| **Метод аутентификации** | Yandex Passport (Device Flow) |
| **Макс. качество звука** | N/A (plugin — не предоставляет аудио) |

Подробное описание всех параметров смотрите в диалоге настройки провайдера в Music Assistant.
